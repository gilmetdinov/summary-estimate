# Бета: запуск и сборка

Два раздела: для **сметчицы** (как пользоваться) и для **сборщика** (как сделать
`.exe` для раздачи).

---

## Для сметчицы — как пользоваться

1. Запустите программу:
   - **Если дали `summary-estimate.exe`** — двойной клик, откроется **окно программы**
     (без всякой консоли).
   - **Если Python установлен** — `python app.py` (то же самое).
2. В окне:
   - **Шаг 1** — кнопка **«Выбрать файлы…»**, отметьте выгрузку(и) из Гранд Сметы /
     Адепта (`.xlsx`). Можно сразу несколько — каждая станет отдельным готовым файлом.
   - **Шаги 2–3** — проверьте/поправьте реквизиты и ФИО подписантов (организация
     и заказчик). Они подставляются по умолчанию, но под конкретный договор можно менять.
   - **Шаг 4** — ставка НДС; при необходимости включите галочками **строку изысканий**
     (НЗ_ИГДИ) и/или **госэкспертизы** — они не приходят из выгрузки и добавляются
     вручную. Стоимость можно вписать сразу, а можно оставить пустой и заполнить
     уже в готовом файле (строка появится в любом случае, «всего» пересчитается само).
3. Нажмите **«Конвертировать»** и укажите, куда сохранить:
   - один файл → имя подставится само из выгрузки (`Сводник_<проект>_<объект>.xlsx`),
     при желании поменяйте;
   - несколько → выберите папку, туда лягут все результаты (имя каждого — по его выгрузке).
4. По готовности программа предложит открыть папку с результатом. Откройте файл в Excel,
   проверьте сводную и листы смет; формулы (итоги, НДС, сумма прописью) пересчитаются
   при открытии.

> Если что-то не распозналось — пришлите исходную выгрузку и текст ошибки из окна.

## Для сборщика — как сделать `.exe`

**Важно:** PyInstaller **не умеет кросс-компиляцию**. Windows-`.exe` собирается
**только на Windows**. На Mac получится только Mac-бинарь (годится для локальной проверки).

### Windows (целевой `.exe`)

1. Поставьте Python 3.10+ с [python.org](https://www.python.org/downloads/)
   (галочка «Add to PATH» при установке).
2. Скопируйте папку проекта на машину, откройте её в проводнике.
3. Двойной клик по **`build.bat`** (или в консоли: `build.bat`).
4. Готовый файл — **`dist\summary-estimate.exe`**. Отдавайте сметчице **только его одного**
   (донор оформления и дефолтный конфиг уже внутри).

### macOS / Linux (проверка сборки)

```bash
bash build.sh        # результат: dist/summary-estimate (не .exe)
./dist/summary-estimate
```

### Мастер-шаблон оформления

- Донор оформления — `template.xlsx` (только два листа-донора). Он уже в репозитории
  и вшивается в exe.
- Эталон-источник `sources/example.xlsx` лежит локально и **не коммитится** (`.gitignore`).
  Если меняли его — перегенерируйте шаблон **до** сборки: `python make_template.py`
  → пересоздаст `template.xlsx`.

### Настройка реквизитов по умолчанию

- Значения формы берутся из `config.json`. Чтобы у тестера были «правильные» дефолты,
  отредактируйте `config.json` **до** сборки — он вшивается в exe.
- Можно и после: положить свой `config.json` **рядом** с `summary-estimate.exe` — он
  переопределит вшитый.

### Проверка перед раздачей

```bash
python3 smoke_test.py            # конвертация + рендер в PDF через LibreOffice
python3 smoke_test.py f1.xlsx f2.xlsx   # на нескольких выгрузках
```

`OK` по всем входам → можно отдавать в бету.
