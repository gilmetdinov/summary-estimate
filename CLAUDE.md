# CLAUDE.md

Гайд для Claude Code по проекту `summary-estimate`. Читается автоматически в начале сессии.

## Что это

RND по автоматизации подготовки сметных форм на **ПИР** (проектно-изыскательские работы,
сметное дело РФ). Цель — заменить ручную переверстку смет в фирменный печатный бланк
и ручную сборку сводных смет.

Четыре направления (детали и статус — в `README.md`):
1. raw → фирменный печатный формат одного проекта — **готов PoC**.
2. Сводный отчёт по нескольким проектам («сводник сводников»).
3. Шаблоны/автоматизация в Гранд Смете + сводные ПИР.
4. Конвертер Адепт → Гранд Смета.

## Текущий статус

PoC №1 реализован и проверен опытной сметчицей (ОК, мелкие замечания). **Бета-сборка готова и собрана в `.exe` на Windows** (2026-06-28): десктопное окно
(tkinter, своя иконка, без консоли, DPI-aware), конфиг реквизитов, мастер-шаблон
`template.xlsx`, плейсхолдеры изысканий/госэкспертизы, батч, smoke-тест. По первой
Windows-сборке отловлены и пофикшены баги (наложение merge в Excel, консоль, мыло,
иконка окна/таскбара, мусорный файл из `build.bat`). **Текущий этап — активная
эксплуатация беты, ждём фидбек.** Следующие шаги — в `README.md` (раздел «RND: 4 направления»
и «Известные ограничения»). **В работу пункты роадмапа брать только по явной просьбе пользователя.**

| `render/` | пакет рендеринга: `convert.py` (оркестрация), `sheet_smeta.py` / `sheet_svodnaya.py` / `sheet_izyskaniya.py` (листы), `donor.py` (мастер-шаблон), `style.py` (хелперы openpyxl) |

| `app.py` | десктопное окно (tkinter) |
| `make_template.py` / `template.xlsx` | сборка и сам мастер-шаблон (2 листа-донора), вкладывается в exe |
| `smoke_test.py` | прогон + рендер через LibreOffice (проверка формул) |
| `tests/` | юнит-тесты (`pytest`): парсер, хелперы рендеринга, конвертация |
| `build.spec` / `build.bat` / `build.sh` | сборка автономного бинаря (PyInstaller) |
| `app.ico` / `app_icon.png` | иконка приложения (exe + окно/панель задач) |
| `requirements.txt` / `requirements-build.txt` | рантайм / сборочные зависимости |
| `README.md` | архитектура, запуск, гэпы, направления RND |
| `sources/` | **локальные данные под `.gitignore`** (не коммитятся): `example.xlsx` (источник шаблона), `raw.xlsx` (образец входа), образцы результата/превью. Реальные сметы заказчиков не в репо. |

## Запуск

```bash
python3 app.py                                        # десктопное окно (для сметчицы)
python3 make_template.py                              # перегенерация шаблона из sources/example.xlsx
python3 smeta_render.py вход.xlsx                     # CLI; имя результата по содержимому
python3 smeta_render.py a.xlsx b.xlsx -o converted/   # батч → папка
python3 smoke_test.py                                 # smoke-тест (sources/raw.xlsx) через LibreOffice
python3 smeta_parser.py sources/raw.xlsx             # проверка модели парсера
```

## Ключевые факты предметки

- Методики Минстроя: **707/пр** (проектная документация), **НЗ_СИТО_ИО**;
  изыскания — **НЗ_ИГДИ**. В сметах ПИР стоимость = разбивка по статьям
  ПЗ/ППО/ТКР/ПОС/ООС/ПБ/СМ + коэффициенты Ки/К/Кинф/Котн.
- **Главный инсайт:** тело таблицы в raw и example структурно идентично — переход
  raw→example это детерминированный шаблонинг + кросс-ссылки, не «умное» преобразование.
- Источник данных — выгрузка из сметной программы (Гранд Смета / Адепт), формат стабильный.
- Изыскания и госэкспертиза в сводную вставляются **вручную** (не из выгрузки ГС).

## Принципы реализации

- **Оформление не генерируется руками**, а копируется вживую из файла-эталона-донора
  (стили/рамки/форматы/высоты/объединения) — так фиделити максимальный.
- Комментарии и текст — **на русском** (предметка русскоязычная).
- «Сумма прописью» — рабочая Excel-формула (ROMAN/SUBSTITUTE), копируется из донора
  с подстановкой адреса итоговой ячейки.

## Окружение и проверка

- `openpyxl` стоит; `pandas` нет. Питон — pyenv.
- Для проверки результата — **LibreOffice headless** (есть в системе):
  `/Applications/LibreOffice.app/Contents/MacOS/soffice --headless --convert-to pdf ...`
  даёт пересчёт формул и рендер → проверяй PDF глазами.
- **Прокси:** WebFetch к рунет-сайтам падает (Socket closed); WebSearch работает.
  Для этой задачи интернет не нужен — всё локально.
- Не git-репозиторий.
