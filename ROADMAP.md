# Roadmap

Статус на 2026-06-28: **бета-сборка готова и собрана в `.exe` на Windows** — десктопное
окно, своя иконка, без консоли. PoC #1 проверен сметчицей; продакшн-харднинг №1 закрыт.
**Текущий этап — активная эксплуатация беты, ждём фидбек.** Дальше — правки по замечаниям
и направление №2.

## Сделано

- [x] **PoC #1: raw → фирменный печатный формат (example)** — парсер + рендерер,
      сохранение оформления, сводная со ссылками, НДС, сумма прописью.
      Проверено прогоном через LibreOffice. Файлы: `smeta_parser.py`, `smeta_render.py`.
- [x] **Бета-пакет (2026-06-28):** конфиг реквизитов (`config.py`/`config.json`),
      десктопное окно (`app.py`, tkinter), мастер-шаблон (`make_template.py`/`template.xlsx`),
      плейсхолдеры изысканий/госэкспертизы, батч-обработка, smoke-тест (`smoke_test.py`),
      сборка под exe (`build.spec`/`build.bat`/`build.sh`), `requirements*.txt`, `БЕТА.md`.
      Логика (конфиг/конвертация/батч/шаблон) проверена на стенде; само окно tkinter —
      на стенде нет `_tkinter`, проверяется на Windows при сборке.

## Продакшн-харднинг №1

- [x] **1. Параметризация заказчиков и ФИО подписантов** — хардкод вынесен в
      `config.json` (см. `config.py`); правится в веб-форме.
- [x] **2. Финальный мастер-шаблон** — `template.xlsx` (только 2 листа-донора со
      стабильными именами `ШАБЛОН_смета`/`ШАБЛОН_сводная`), генерируется из эталона
      через `make_template.py`; рендерер и сборка ссылаются на него. `example.xlsx`
      остался эталоном/фикстурой и от прода отвязан.
- [x] **3. Плейсхолдеры для изысканий и госэкспертизы** — опциональные строки сводной
      (НЗ_ИГДИ / госэкспертиза) через форму или `config.json`; входят в SUM/НДС/нумерацию.
- [x] **4. Простой интерфейс ввода базовых данных** — `app.py` (десктопное окно tkinter):
      реквизиты, ФИО, НДС, опц. изыскания/экспертиза; выбор выгрузки(ок) → конвертация → сохранение.
- [x] **5. Батч-обработка выгрузок ГС** — несколько выгрузок за прогон (CLI и окно);
      результат пачкой в выбранную папку. Один конфиг на все.
- [x] **6. Подготовка venv** — `requirements.txt` (рантайм) и `requirements-build.txt`
      (сборка), фиксация версий, инструкция в `БЕТА.md`.
- [x] **7. Сборка в .exe** — `build.spec` (PyInstaller, вложение донора/конфига/иконки,
      `resource_path`) + `build.bat` (`chcp`, idempotent venv, `--clean`) / `build.sh`.
      Собран и запущен на Windows: окно без консоли, DPI-aware, своя иконка.
